VS Code · GitHub Copilot

Cài skill vào workspace

Tài liệu VS Code ↗
01

Tạo skill trong VS Code

Mở Chat → Open Customizations → Skills → New Skill, chọn Workspace và nhập tên skill.

02

Copy file hoàn chỉnh

Chọn một thẻ skill, mở chi tiết rồi nhấn Copy for VS Code. Dán toàn bộ nội dung vào `SKILL.md` vừa tạo, thay template.

03

Kiểm tra đường dẫn và dùng

Skill workspace nằm tại .github/skills/<skill-name>/SKILL.md. Tên thư mục phải trùng với name trong frontmatter. Có thể gọi trực tiếp bằng /<skill-name>; mô tả yêu cầu liên quan cũng giúp Copilot tự chọn skill, nhưng không bảo đảm skill sẽ được gọi trong mọi lượt phù hợp.

Muốn cài thủ công: tạo thư mục `.github/skills/<skill-name>` trong workspace đang mở và lưu nội dung đã copy thành `SKILL.md`. VS Code phát hiện skill từ thư mục hỗ trợ và có thể nạp khi thấy liên quan, nhưng discovery không phải cam kết invocation. Nếu cần chắc chắn dùng đúng playbook, gọi slash command như /risk-based-test-design trực tiếp trong chat.

          🟢 Module 1: Security Logging Foundations

          OWASP A09:2025 - Security Logging Failures

          Bài 1: Exists Query - Phát hiện "Điểm mù"

          Easy
          Scenario: Sau một đợt cập nhật microservice, Parser bị lỗi khiến các sự kiện đăng nhập không ghi nhận kết quả (Success/Failure).
          JSON
          GET logs-*/_search
{
  "query": {
    "bool": {
      "must": [{ "match": { "event.category": "authentication" } }],
      "must_not": [{ "exists": { "field": "event.outcome" } }]
    }
  }
}
          • Kiểm tra chất lượng Log: Tìm các bản ghi thiếu trường @timestamp.
          • Bảo mật: Phát hiện các request không có user.id trong hệ thống yêu cầu định danh.
          🎯 Thử thách

          Tìm log của service payment-gateway thiếu field transaction.id.

          Xem đáp án
          {
  "query": {
    "bool": {
      "must": [{ "term": { "service.name": "payment-gateway" } }],
      "must_not": [{ "exists": { "field": "transaction.id" } }]
    }
  }
}
          OWASP A02:2025 - Cryptographic Failures

          Bài 2: Sensitive Data - Phát hiện rò rỉ thông tin

          Easy
          Scenario: Developer vô tình log toàn bộ request body chứa password hoặc api_key lên production.
          JSON
          GET logs-*/_search
{
  "query": {
    "bool": {
      "should": [
        { "match_phrase": { "message": "password" } },
        { "match_phrase": { "message": "token" } }
      ],
      "minimum_should_match": 1
    }
  }
}
          • DLP: Săn tìm số thẻ tín dụng hoặc thông tin PII rò rỉ.
          • Compliance: Đảm bảo không có dữ liệu nhạy cảm nào được lưu trữ ở dạng clear-text trong log.
          🎯 Thử thách

          Thêm keyword private_key và client_secret vào query trên.

          Xem đáp án
          {
  "query": {
    "bool": {
      "should": [
        { "match_phrase": { "message": "private_key" } },
        { "match_phrase": { "message": "client_secret" } }
      ],
      "minimum_should_match": 1
    }
  }
}

          🟡 Module 2: Observability & Behavioral Analysis

          OWASP A07:2025 - Auth Failures

          Bài 7: Brute Force - Phân tích ngưỡng

          Medium
          Scenario: Phát hiện các IP có hành vi dò mật khẩu với tần suất cao (>20 lần/phút).
          JSON
          GET logs-*/_search
{
  "query": {
    "bool": {
      "filter": [
        { "term": { "event.outcome": "failure" } },
        { "range": { "@timestamp": { "gte": "now-1m" } } }
      ]
    }
  },
  "aggs": {
    "suspicious_ips": { "terms": { "field": "source.ip", "min_doc_count": 20 } }
  }, "size": 0
}
          • Security: Chặn IP tấn công tự động.
          • Rate Limiting: Nhận diện các user đang spam API quá mức cho phép.
          🎯 Thử thách

          Thống kê Top 5 người dùng (user.name) có số lượng request bị lỗi 403 cao nhất.

          Xem đáp án
          {
  "size": 0,
  "query": { "term": { "http.response.status_code": 403 } },
  "aggs": {
    "top_users": { "terms": { "field": "user.name", "size": 5 } }
  }
}

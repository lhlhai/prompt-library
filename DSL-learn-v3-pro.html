          🟢 Module 1: Security Logging Foundations

          OWASP A09:2025 - CWE-223

          Bài 1: Exists Query - Phát hiện "Điểm mù"

          Easy
          Scenario: Sau một đợt cập nhật microservice, Parser bị lỗi khiến các sự kiện đăng nhập không ghi nhận kết quả (Success/Failure).
          💡 Use Case thực tế
          • Kiểm soát chất lượng dữ liệu: Đảm bảo tất cả log từ firewall đều có trường action.
          • Bảo mật: Tìm các request truy cập vào API nhạy cảm mà thiếu trường user.id.
          GET logs-*/_search
{
  "query": {
    "bool": {
      "must": [{ "match": { "event.category": "authentication" } }],
      "must_not": [{ "exists": { "field": "event.outcome" } }]
    }
  }
}
          ❌ Anti-pattern

          Sử dụng match: "". Elasticsearch coi field thiếu hoàn toàn khác với string rỗng.

          🎯 Bài tập thực hành

          Viết query tìm tất cả log của service payment-gateway mà bị thiếu trường transaction.id.

          {
  "query": {
    "bool": {
      "must": [{ "term": { "service.name": "payment-gateway" } }],
      "must_not": [{ "exists": { "field": "transaction.id" } }]
    }
  }
}
          OWASP A02:2025 - Cryptographic Failures

          Bài 2: Sensitive Data - Phát hiện rò rỉ thông tin

          Easy
          Scenario: Developer vô tình log toàn bộ request body chứa password hoặc api_key lên production.
          💡 Use Case thực tế
          • DLP (Data Loss Prevention): Quét log định kỳ để tìm các chuỗi giống số thẻ tín dụng hoặc số điện thoại.
          • Audit: Tìm kiếm các hành động nhạy cảm trong message log như "delete user" hoặc "change permission".
          GET logs-*/_search
{
  "query": {
    "bool": {
      "should": [
        { "match_phrase": { "message": "password" } },
        { "match_phrase": { "message": "token" } },
        { "match_phrase": { "message": "api_key" } }
      ],
      "minimum_should_match": 1
    }
  }
}
          🎯 Bài tập thực hành

          Cập nhật query trên để tìm thêm các log chứa cụm từ "private_key" hoặc "client_secret".

          {
  "query": {
    "bool": {
      "should": [
        { "match_phrase": { "message": "private_key" } },
        { "match_phrase": { "message": "client_secret" } }
      ],
      "minimum_should_match": 1
    }
  }
}
          OWASP A07:2025 - Auth Failures

          Bài 4: Brute Force - Phân tích ngưỡng

          Medium
          Scenario: Phát hiện các IP có hành vi dò mật khẩu với tần suất cao (>20 lần/phút).
          💡 Use Case thực tế
          • Chống tấn công từ chối dịch vụ (DoS): Tìm các IP gửi quá nhiều request trong thời gian ngắn.
          • Giám sát hệ thống: Thống kê các service đang gặp nhiều lỗi 5xx nhất.
          GET logs-*/_search
{
  "query": {
    "bool": {
      "filter": [
        { "term": { "event.outcome": "failure" } },
        { "range": { "@timestamp": { "gte": "now-1m" } } }
      ]
    }
  },
  "aggs": {
    "suspicious_ips": { "terms": { "field": "source.ip", "min_doc_count": 20 } }
  }, "size": 0
}
          🎯 Bài tập thực hành

          Thống kê Top 5 người dùng (user.name) có số lượng request bị lỗi 403 (Forbidden) cao nhất trong 1 giờ qua.

          {
  "size": 0,
  "query": {
    "bool": {
      "filter": [
        { "term": { "http.response.status_code": 403 } },
        { "range": { "@timestamp": { "gte": "now-1h" } } }
      ]
    }
  },
  "aggs": {
    "top_violators": {
      "terms": { "field": "user.name", "size": 5 }
    }
  }
}

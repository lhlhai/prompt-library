          🟢 Module 1: Security Logging Foundations

          OWASP A09:2025 - CWE-223

          Bài 1: Exists Query - Phát hiện "Điểm mù"

          Easy
          Scenario: Sau một đợt cập nhật microservice, Parser bị lỗi khiến các sự kiện đăng nhập không ghi nhận kết quả (Success/Failure).
          GET logs-*/_search
{
  "query": {
    "bool": {
      "must": [{ "match": { "event.category": "authentication" } }],
      "must_not": [{ "exists": { "field": "event.outcome" } }]
    }
  }
}
          ❌ Anti-pattern

          Sử dụng match: "". Elasticsearch coi field thiếu hoàn toàn khác với string rỗng.

          🎯 Thực hành

          Tìm log của service payment-gateway thiếu field transaction.id.

          OWASP A02:2025 - Cryptographic Failures

          Bài 2: Sensitive Data - Phát hiện rò rỉ thông tin

          Easy
          Scenario: Developer vô tình log toàn bộ request body chứa password hoặc api_key lên production.
          GET logs-*/_search
{
  "query": {
    "bool": {
      "should": [
        { "match_phrase": { "message": "password" } },
        { "match_phrase": { "message": "token" } },
        { "match_phrase": { "message": "api_key" } }
      ],
      "minimum_should_match": 1
    }
  }
}
          🎯 Thực hành

          Thêm keyword private_key và client_secret vào query.

          OWASP A07:2025 - Auth Failures

          Bài 4: Brute Force - Phân tích ngưỡng

          Medium
          Scenario: Phát hiện các IP có hành vi dò mật khẩu với tần suất cao (>20 lần/phút).
          GET logs-*/_search
{
  "query": {
    "bool": {
      "filter": [
        { "term": { "event.outcome": "failure" } },
        { "range": { "@timestamp": { "gte": "now-1m" } } }
      ]
    }
  },
  "aggs": {
    "suspicious_ips": { "terms": { "field": "source.ip", "min_doc_count": 20 } }
  }, "size": 0
}

          🟡 Module 2: Observability & Behavioral Analysis

          OWASP A01:2025 - Broken Access Control

          Bài 8: Nested Headers - Tìm Header Nhạy Cảm

          Medium
          Scenario: Kiểm tra xem có request nào chứa Authorization header bị log ra ở dạng nested object không.
          GET logs-*/_search
{
  "query": {
    "nested": {
      "path": "http.request.headers",
      "query": { "match": { "http.request.headers.name": "Authorization" } }
    }
  }
}
          Risk Analysis

          Bài 10: Painless Script - Chấm điểm rủi ro (Risk Scoring)

          Hard
          Scenario: Tự động tính điểm rủi ro cho mỗi log dựa trên status code và kết quả event.
          GET logs-*/_search
{
  "script_fields": {
    "risk_score": {
      "script": {
        "source": "int s=0; if(doc['event.outcome.keyword'].value=='failure') s+=30; if(doc['http.response.status_code'].value >= 500) s+=40; return s;"
      }
    }
  }
}

          Bài 14: ML Anomaly Detection - Phát hiện "Unknown Threats"

          Hard
          Scenario: Sử dụng Machine Learning để phát hiện các hành vi đăng nhập bất thường mà không cần cấu hình ngưỡng cứng.

          🛡️ Module 4: Advanced OWASP Attack Detection

          OWASP A01:2025

          Bài 20: Privilege Escalation - Leo thang đặc quyền

          Hard
          Scenario: Phát hiện user thông thường cố gắng truy cập các endpoint quản trị hoặc thay đổi quyền hạn.
          GET logs-*/_search
{
  "query": {
    "bool": {
      "must": [
        { "match": { "url.path": "/api/admin/*" } },
        { "must_not": { "match": { "user.roles": "admin" } } }
      ]
    }
  }
}
          OWASP A05:2025

          Bài 21: Misconfiguration - Phát hiện Open Ports

          Medium
          Scenario: Quét log network để tìm các traffic không mong muốn hướng tới các port nhạy cảm (22, 3389, 9200) từ internet.
          GET logs-*/_search
{
  "query": {
    "bool": {
      "must": [
        { "terms": { "destination.port": [22, 3389, 9200] } },
        { "must_not": { "match": { "source.ip": "internal-range-*" } } }
      ]
    }
  }
}
          OWASP A10:2025

          Bài 19: SSRF - Outbound Request Audit

          Hard
          Scenario: Phát hiện các request từ app server hướng tới dải IP nội bộ hoặc metadata service của Cloud (169.254.169.254).
          GET logs-*/_search
{
  "query": {
    "bool": {
      "filter": [
        { "terms": { "destination.ip": ["10.0.0.0/8", "169.254.169.254", "127.0.0.1"] } }
      ]
    }
  }
}

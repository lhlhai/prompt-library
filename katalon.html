📖 Giới thiệu về Katalon Studio

Katalon Studio là một công cụ automation testing toàn diện hỗ trợ kiểm thử tự động cho Web, API, Mobile và Desktop applications. Được xây dựng dựa trên nền tảng Selenium và Appium, Katalon cung cấp giải pháp "all-in-one" giúp tester dễ dàng tiếp cận automation mà không cần nhiều kiến thức về lập trình.

🌐 Web Testing

Automated testing cho các ứng dụng web trên nhiều trình duyệt khác nhau (Chrome, Firefox, Edge, Safari)

📱 Mobile Testing

Kiểm thử ứng dụng mobile trên cả iOS và Android với support cho real devices và emulators

🔌 API Testing

Test RESTful và SOAP APIs với đầy đủ các phương thức HTTP và validation

💻 Desktop Testing

Automation cho ứng dụng desktop trên Windows với support cho WinAppDriver

💡 Tại sao chọn Katalon Studio?

Katalon Studio được thiết kế đặc biệt cho tester với giao diện trực quan, hỗ trợ cả manual view (không cần code) và script view (cho advanced users). Đây là lựa chọn hoàn hảo cho Manual Tester muốn bắt đầu hành trình automation mà không bị choáng ngợp bởi code phức tạp.

🔍 Tổng quan về Katalon Studio

Katalon Studio là gì?

Katalon Studio là một Integrated Development Environment (IDE) cho automation testing, cung cấp đầy đủ các tính năng cần thiết để tạo, thực thi và quản lý test cases tự động. Với Katalon, bạn có thể bắt đầu ngay mà không cần cài đặt thêm thư viện hay cấu hình phức tạp.

Các tính năng chính

🎬 Record & Playback

Ghi lại thao tác của bạn trên ứng dụng và tự động tạo test case. Perfect cho người mới bắt đầu!

📝 Manual View

Tạo test steps bằng cách chọn keywords từ dropdown - không cần viết code!

💻 Script View

Viết code Groovy/Java cho các logic phức tạp khi bạn đã sẵn sàng

📊 Data-driven Testing

Chạy cùng test case với nhiều bộ dữ liệu khác nhau từ Excel, CSV, Database

🔄 CI/CD Integration

Tích hợp với Jenkins, GitLab CI, Azure DevOps để chạy test tự động trong pipeline

📈 Báo cáo chi tiết

Xem kết quả test với screenshots, logs, và video recording khi test fail

Cấu trúc project Katalon điển hình

📁 Test Cases/
- Chứa các test cases individual
📁 Object Repository/
- Chứa các đối tượng (element locators)
📁 Keywords/
- Chứa custom keywords (hàm tái sử dụng)
📁 Test Suites/
- Nhóm các test cases lại với nhau
📁 Profiles/
- Chứa biến môi trường (dev, staging, prod)
📁 Data Files/
- Chứa file dữ liệu cho data-driven testing

📚 Lộ trình học chi tiết

Lộ trình này được thiết kế trong 6 tuần, chia thành 3 giai đoạn phù hợp cho Manual Tester.

Giai đoạn 1: Tuần 1-2

Cơ bản - Làm quen và chạy được test

🎯 Mục tiêu

Hiểu được cấu trúc project, biết cách mở và chạy test case có sẵn

📋 Nội dung học

  1. Cài đặt Katalon Studio - Tải từ katalon.com
  2. Làm quen với giao diện:
    • Test Explorer - xem cấu trúc project
    • Test Case Editor - xem và chỉnh sửa test cases
    • Toolbar - các nút điều khiển và chạy test
  3. Hiểu cấu trúc thư mục project:
    • Test Cases - chứa các kịch bản test
    • Object Repository - lưu trữ element locators
    • Keywords - các hàm reusable
    • Test Suites - nhóm test cases
    • Profiles - cấu hình môi trường
  4. Quan trọng: Mở project có sẵn (file zip) và chạy thử test case
  5. Tìm hiểu Manual View - Tạo test step bằng cách chọn keyword từ dropdown
  6. Làm quen với Built-in Keywords:
    • WebUI.openBrowser() - Mở trình duyệt
    • WebUI.navigateToUrl() - Điều hướng đến URL
    • WebUI.click() - Click vào element
    • WebUI.setText() - Nhập text vào field
    • WebUI.verifyElementPresent() - Kiểm tra element tồn tại
  7. Chạy test case và xem report - Phân tích kết quả test

Giai đoạn 2: Tuần 3-4

Trung cấp - Hiểu và chỉnh sửa test case

🎯 Mục tiêu

Biết cách đọc hiểu test case, sửa lỗi, thêm mới test case

📋 Nội dung học

  1. Hiểu rõ Test Case:
    • Cách tạo mới test case
    • Các thành phần của một test case
    • Test case lifecycle
  2. Sử dụng Record & Playback để tạo test case nhanh chóng
  3. Quản lý Object Repository:
    • Hiểu cách Katalon lưu element locators
    • Cập nhật object khi UI thay đổi
    • Tổ chức object theo page/module
  4. Sử dụng Test Suites:
    • Group test cases lại với nhau
    • Chạy nhiều test cases cùng lúc
    • Thiết lập execution order
  5. Sử dụng Profiles:
    • Quản lý biến môi trường
    • URL, username, password cho từng environment
    • Switch giữa dev, staging, production
  6. Data-driven Testing:
    • Chạy cùng test case với nhiều bộ dữ liệu
    • Sử dụng Excel, CSV files
    • Parameterization trong test cases
  7. Xem và phân tích test report:
    • Đọc execution logs
    • Xem screenshots khi fail
    • Export báo cáo

Giai đoạn 3: Tuần 5-6

Nâng cao - Maintenance và mở rộng

🎯 Mục tiêu

Biết cách bảo trì test case khi ứng dụng thay đổi, viết custom keyword

📋 Nội dung học

  1. Test Maintenance - Khi ứng dụng thay đổi:
    • Self-healing mechanism: Tự động sửa locator bị broken
    • Failure handling settings: Cấu hình xử lý khi test fail
    • Time Capsule: Xem snapshot của ứng dụng khi test fail
    • Refactor test objects: Xóa/update object không dùng
  2. Custom Keywords:
    • Viết hàm tái sử dụng bằng Groovy
    • Import vào test cases
    • Best practices cho custom keywords
  3. Test Listeners:
    • Chạy code trước/sau test suite (setUp/tearDown)
    • Global setup and teardown
    • Capture screenshots on failure
  4. Tích hợp CI/CD:
    • Chạy test tự động với Jenkins
    • Command line execution
    • Integration với Git
  5. Testing API với Katalon:
    • Tạo API test cases
    • Validate response
    • Chain API requests

🛠️ Kỹ năng cần thiết cho Manual Tester

Phần này đặc biệt quan trọng vì tình huống thực tế của bạn là nhận file zip bao gồm Katalon exe + testsuite, test case, config - đây là 1 framework đang chạy.

1. Cách mở project từ file zip

  1. Giải nén file zip vào một thư mục trên máy tính
  2. Mở Katalon Studio
  3. Vào menu File → Open Project
  4. Chọn thư mục project vừa giải nén
  5. Hoặc: File → Import → Existing Katalon Project

2. Cách đọc hiểu cấu trúc project có sẵn

📂 Xem Test Suites

Xem thư mục Test Suites/ để biết có những suite nào, mỗi suite chứa những test cases gì

📝 Mở Test Cases

Mở từng test case để xem các step bên trong, hiểu flow của test

⚙️ Xem Profiles

Kiểm tra file Profiles/ để biết cấu hình môi trường (URL, credentials, etc.)

🎯 Object Repository

Xem cách các elements được định nghĩa và tổ chức trong project

3. Cách chạy test

  • Chạy 1 test case: Mở test case → Click nút Run (hoặc Ctrl+F9)
  • Chạy 1 test suite: Mở test suite → Click nút Run
  • Chạy nhiều test suites: Tạo Test Suite Collection để group và chạy nhiều suites
  • Chạy từ command line: Sử dụng console mode cho CI/CD integration

4. Cách thêm mới test case

  1. Right-click vào folder Test Cases/ → New → Test Case
  2. Chọn Manual View hoặc Script View tùy preference
  3. Thêm test steps bằng cách chọn keywords từ dropdown
  4. Configure test data và parameters nếu cần
  5. Thêm test case vào test suite phù hợp
  6. Run để verify test case mới hoạt động đúng

5. Cách maintenance test case khi application thay đổi

Bước 1: Xác định test case bị fail

Xem report sau khi chạy test để biết test case nào fail, error message là gì

Bước 2: Tìm nguyên nhân

  • Object locator thay đổi? (UI elements bị change ID, class, XPath...)
  • Logic thay đổi? (Flow của application bị modify)
  • Data thay đổi? (Test data không còn valid)

Bước 3: Sửa object trong Object Repository

Dùng Spy Web để capture lại element với locator mới, update vào Object Repository

Bước 4: Sửa logic trong test case

Update test steps, thêm/xóa steps, modify conditions nếu cần

Bước 5: Chạy lại để verify

Execute test case để đảm bảo fix hoạt động đúng, không gây side effects

💡 Mẹo maintenance hiệu quả

Sử dụng tính năng Self-healing của Katalon để tự động phát hiện và đề xuất locator alternatives khi element không tìm thấy. Enable tính năng này trong Project Settings → Execution.

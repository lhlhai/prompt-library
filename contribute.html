Bảng vàng contributor 🏆

Những người có PR đã được merge vào dự án. Danh sách lấy trực tiếp từ GitHub và tự cập nhật sau mỗi lần đóng góp được hợp nhất.

Why contribute?

Lợi ích chính đáng, không nói điêu 🤝

Đóng góp open source không chỉ là "cho đi". Đây là những gì bạn nhận lại, hoàn toàn miễn phí:

🏷️

Profile GitHub đẹp hơn

Một green square nhỏ trên profile graph có sức mạnh khó tin với nhà tuyển dụng. PR đầu tiên là bước khởi đầu.

🧠

Học Git thật chiến

Fork, branch, rebase, resolve conflict — những thứ interview hay hỏi, bạn sẽ thành thạo sau 2 tuần contribute.

🪞

Code review miễn phí

Nhận feedback từ người dùng thật, cho sản phẩm thật. Giá của việc này nếu đi học khóa khác là... khá chát.

🌱

Cà chua xanh cũng được

Sửa typo, dịch tài liệu, thêm ví dụ — mọi đóng góp đều tính. Không ai phán xét size of your first PR.

🎸

Được ghi danh

Tên bạn xuất hiện trong Wall of Fame của dự án. Vĩnh viễn. Trừ khi bạn yêu cầu gỡ xuống (tụi tôi buồn lắm).

😂

Vui là chính

Trang này bạn đang đọc cũng là kết quả của một PR. Tinh thần: chia sẻ kiến thức, nhận lại tiếng cười và commit credit.

The ritual

5 bước tới PR đầu tiên ⚡

Toàn bộ nghi thức mở hàng contributor, rút gọn còn bằng ly cà phê sáng:

Fork repo 🍴

Bấm nút Fork trên GitHub. Từ giây phút đó, bạn sở hữu một bản sao vũ trụ song song của dự án.

Clone & tạo nhánh

Kéo code về máy, tạo riêng một nhánh cho ý tưởng của bạn. Nhánh tên gợi ý: feat/ten-ban-thich.

zsh — contribute.sh
$ git clone https://github.com/<bạn>/prompt-library.git
$ cd prompt-library && git checkout -b fix/typo-trang-hero

Sửa gì cũng được (thật ra là được)

Thêm prompt, sửa mô tả, viết note, dịch thuật, tối ưu CSS, hoặc thêm một emoji cho đời vui hơn. Mở file bằng editor bạn yêu — VS Code, Vim, hay Notepad chúng tôi đều tôn trọng.

Commit & push

Message commit nên trả lời câu hỏi "tại sao", không phải "cái gì". Ví dụ: docs: thêm mục ESLint cho newbie.

git — the force
$ git add .
$ git commit -m "feat: thêm trang đóng góp siêu hài"
$ git push origin fix/typo-trang-hero
# GitHub sẽ gửi cho bạn một link Pull Request. Bấm vào. Tin tốt đang chờ.

Mở Pull Request & chill ☕

Viết mô tả ngắn gọn, gắn label nếu thích, rồi đi uống cà phê. maintainer (tức là tác giả, tức là rất nhanh đáp) sẽ review, comment và merge. Welcome to open source!

Good first ideas

Chưa biết làm gì? Cầm tạm ý tưởng này 💡

Chọn một thẻ bên dưới, coi như menu khai vị. Ăn ngon thì quay lại order thêm:

✏️Easy

Săn typo

Đọc các trang trong repo, tìm lỗi chính tả/tiếng Việt lạ tai và sửa. Đóng góp nhỏ, tự tin to.

⏱ ~10 phút · 0 dòng code
🧩Easy

Thêm prompt hay

Bạn có prompt nào đã kiểm chứng qua công việc thật? Thêm vào kho prompt cho cộng đồng dùng chung.

⏱ ~20 phút · 1 file data
🌐Easy

Dịch tài liệu

Việt ↔ Anh README, guide, chú thích trong các mô phỏng. Cơ hội để cả thế giới hiểu project.

⏱ ~30 phút · markdown
🎨Medium

Dark mode cho trang cũ

Một số trang lâu năm chưa sync theme. Thêm biến CSS, test hai chế độ, thành hero UX.

⏱ ~1 giờ · CSS
🧪Medium

Thêm quiz cho SIT Lab

Mô phỏng IT/ST/SIT đang khát câu hỏi. Viết thêm 3–5 câu kèm giải thích, người học cảm ơn bạn lắm.

⏱ ~1 giờ · JS
🃏Wild

House rules

Nội quy — phiên bản dễ thương 🐣

💖
Tôn trọng nhau, hết.

Mọi văn hóa, mọi trình độ đều welcome. Feedback nặng nề → bị trừ điểm cà phê.

🧪
Test trước khi PR.

Mở trang bạn sửa bằng trình duyệt, bấm thử vài nút. Nửa phút tiết kiệm cho maintainer nửa ngày.

📝
PR nhỏ mà đều > PR khổng lồ.

Chia thay đổi lớn thành nhiều PR. Review 20 dòng vui hơn review 2000 dòng rất nhiều.

🚫
Không spam AI-generated slop.

Chúng tôi dùng AI mỗi ngày, nhưng PR copy-paste nguyên khối không đọc lại thì... please don't.

🎯
Một PR, một mục đích.

Sửa typo đừng kèm đổi font. Trộn hai thứ vào nhau là cách nhanh nhất để PR bị "discuss forever".

🎉
Mừng nhau khi merge.

Comment "GG!" khi PR được merge là truyền thống đẹp. Hãy duy trì, vì tác giả rất thích được khen.

Bài 1 — exists query: Phát hiện Log Thiếu Field Bắt Buộc

OWASP A09: CWE-223 — Information Omission

Mục tiêu: Tìm auth event thiếu event.outcome (không biết thành công hay thất bại)

Kibana Dev Tools 
GET logs-*/_search
{
  "query": {
    "bool": {
      "must": [
        { "match": { "event.category": "authentication" } }
      ],
      "must_not": [
        { "exists": { "field": "event.outcome" } }
      ]
    }
  }
}

🎯 Bài tập thực hành

  • Tìm tất cả HTTP request thiếu field source.ip
  • Tìm log có event.type: error nhưng thiếu error.message
  • Tìm transaction thiếu cả user.id lẫn user.name cùng lúc
💡 Gợi ý: Kết quả hits.total.value > 0 nghĩa là có vấn đề cần fix.

Bài 2 — match + bool.should: Sensitive Data

OWASP A09: CWE-532 — Sensitive Information in Log

Mục tiêu: Tìm log chứa password, token, secret bị lộ

JSON DSL 
GET logs-*/_search
{
  "query": {
    "bool": {
      "should": [
        { "match_phrase": { "message": "password" } },
        { "match_phrase": { "message": "token" } },
        { "match_phrase": { "message": "Authorization" } },
        { "match_phrase": { "message": "secret" } },
        { "match_phrase": { "message": "api_key" } }
      ],
      "minimum_should_match": 1
    }
  }
}

🎯 Bài tập thực hành

  • Thêm keyword private_key, client_secret vào query
  • Tìm log chứa pattern email (@) trong message
  • Tìm log chứa SĐT VN (09/08) dùng wildcard

Bài 3 — regexp query: Phát Hiện Log Injection

OWASP A09: CWE-117 — Improper Output Neutralization

Mục tiêu: Tìm CRLF injection (\r, \n) trong log

GET logs-*/_search
{
  "query": {
    "bool": {
      "should": [
        { "match_phrase": { "message": "\\n" } },
        { "match_phrase": { "message": "\\r\\n" } },
        { "regexp": { "message": ".*(%0a|%0d|%0d%0a).*" } }
      ],
      "minimum_should_match": 1
    }
  }
}

🎯 Bài tập thực hành

  • Tìm URL-encoded injection trong url.query
  • Tìm payload XSS: <script>, onerror=
  • Tìm SQL injection: OR 1=1, UNION SELECT

Bài 4 — range + aggs: Phát Hiện Brute Force

Mục tiêu: Tìm user bị failed login nhiều lần trong 5 phút

GET logs-*/_search
{
  "query": {
    "bool": {
      "must": [
        { "match": { "event.outcome": "failure" } },
        { "match": { "event.category": "authentication" } },
        { "range": { "@timestamp": { "gte": "now-5m" } } }
      ]
    }
  },
  "aggs": {
    "by_user": {
      "terms": { "field": "user.name.keyword", "size": 10 }
    }
  },
  "size": 0
}

Bài 7 — HTTP 5xx Không Có Error Context

GET logs-*/_search
{
  "query": {
    "bool": {
      "must": [{ "range": { "http.response.status_code": { "gte": 500 } } }],
      "must_not": [{ "exists": { "field": "error.message" } }]
    }
  }
}

  "query": {
    "nested": {
      "path": "http.request.headers",
      "query": {
        "match": { "http.request.headers.name": "Authorization" }
      },
      "inner_hits": {}
    }
  }

GET logs-*/_search
{
  "aggs": {

      "aggs": {
        "alert_count": { "value_count": { "field": "rule.name.keyword" } },
        "alert_rate_change": { "derivative": { "buckets_path": "alert_count" } }

    }
  },
  "size": 0
}

Bài 10 — Painless Script: Tính Risk Score

GET logs-*/_search
{
  "script_fields": {
    "risk_score": {
      "script": {
        "lang": "painless",
        "source": """
          int score = 0;
          if (doc['event.outcome.keyword'].value == 'failure') score += 30;
          if (doc['http.response.status_code'].value >= 500) score += 40;
          return score;
        """
      }
    }
  }
}

THEORY · REAL-LIFE EXAMPLES

Mỗi loại giải quyết một bài toán

Đọc sau khi chạy flow
◫

Session Storage

Lý thuyết: ngăn riêng của từng tab, hợp với dữ liệu tạm.

Ví dụ: form đặt vé đang điền dở hoặc bước hiện tại của checkout.

Nhớ nhanh: đóng tab là dọn ngăn.

▣

Local Storage

Lý thuyết: key-value nhỏ, cùng website đọc lại được sau reload.

Ví dụ: dark mode, ngôn ngữ, sidebar đang mở hay đóng.

Nhớ nhanh: cài đặt của người dùng.

⚡

Cache

Lý thuyết: bản sao để giảm thời gian tải; cache không phải nguồn dữ liệu gốc.

Ví dụ: ảnh logo, file CSS, JavaScript hoặc API response có thể tải lại.

Nhớ nhanh: ưu tiên tốc độ, chấp nhận bản sao.

▤

Database · IndexedDB

Lý thuyết: kho có cấu trúc, chứa nhiều records và hỗ trợ query/index.

Ví dụ: app offline lưu hàng nghìn sản phẩm, ghi chú hoặc bản đồ.

Nhớ nhanh: nhiều dữ liệu, cần tìm kiếm.

🍪

Cookies

Lý thuyết: mẩu dữ liệu nhỏ mà browser có thể gửi kèm request tới server.

Ví dụ: session đăng nhập, lựa chọn ngôn ngữ hoặc giỏ hàng do server quản lý.

Nhớ nhanh: browser ↔ server.

↶

History

Lý thuyết: stack các URL/entry để điều hướng, không phải tủ lưu dữ liệu app.

Ví dụ: SPA dùng pushState để nút Back quay về màn hình trước.

Nhớ nhanh: đường đi, không phải hồ sơ.

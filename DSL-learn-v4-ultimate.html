          Module 1: Search Fundamentals

          OWASP A09:2025 - Security Logging Failures

          Bài 1: Exists Query - Tìm kiếm "Dữ liệu mất tích"

          Dễ
          Tình huống: Sau khi nâng cấp hệ thống, bạn nghi ngờ một số log đăng nhập không được ghi nhận kết quả (field event.outcome bị thiếu).

          Query exists giúp tìm các tài liệu có chứa một trường cụ thể. Khi kết hợp với must_not, nó trở thành công cụ đắc lực để tìm các bản ghi bị lỗi mapping hoặc thiếu dữ liệu quan trọng.

          JSON - Elasticsearch DSL
          GET logs-*/_search
{
  "query": {
    "bool": {
      "must_not": [
        { "exists": { "field": "event.outcome" } }
      ]
    }
  }
}
          • Kiểm tra chất lượng Log: Phát hiện các bản ghi thiếu @timestamp hoặc service.name.
          • Bảo mật: Tìm các request không có user.id (có thể là truy cập ẩn danh trái phép).
          • Debug: Tìm các transaction thiếu trace.id để xử lý lỗi tracing.
          Thử thách cho bạn

          Viết query tìm tất cả các log từ service auth-gateway mà thiếu trường source.ip.

          Xem đáp án
          {
  "query": {
    "bool": {
      "must": [{ "term": { "service.name": "auth-gateway" } }],
      "must_not": [{ "exists": { "field": "source.ip" } }]
    }
  }
}
          OWASP A02:2025 - Cryptographic Failures

          Bài 2: Match Phrase - Săn tìm dữ liệu nhạy cảm

          Dễ
          Tình huống: Developer vô tình bật log debug trên production, khiến các chuỗi nhạy cảm như "password=" hoặc "bearer token" xuất hiện trong log.

          match_phrase yêu cầu các từ phải xuất hiện đúng thứ tự và nằm cạnh nhau, giúp giảm nhiễu (False Positive) so với match thông thường.

          JSON - Elasticsearch DSL
          GET logs-*/_search
{
  "query": {
    "match_phrase": {
      "message": "password is"
    }
  }
}
          • DLP (Data Loss Prevention): Tìm kiếm số thẻ tín dụng, email, hoặc API key rò rỉ trong log.
          • Audit: Tìm các hành động cụ thể như "deleted database" hoặc "changed permissions".
          Thử thách cho bạn

          Viết query tìm log chứa cụm từ chính xác "access denied for user admin".

          Xem đáp án
          {
  "query": {
    "match_phrase": {
      "message": "access denied for user admin"
    }
  }
}

          Module 2: Advanced Filtering & Aggs

          OWASP A07:2025 - Identification & Auth Failures

          Bài 7: Terms Aggregation - Phát hiện Brute Force

          Trung bình
          Tình huống: Bạn cần tìm ra những IP nào đang thử đăng nhập sai quá nhiều lần trong 5 phút qua.

          Sử dụng aggs (Aggregations) để nhóm dữ liệu theo source.ip và lọc những nhóm có số lượng bản ghi lớn hơn một ngưỡng nhất định bằng min_doc_count.

          JSON - Aggregation
          GET logs-*/_search
{
  "size": 0,
  "query": {
    "bool": {
      "filter": [
        { "term": { "event.outcome": "failure" } },
        { "range": { "@timestamp": { "gte": "now-5m" } } }
      ]
    }
  },
  "aggs": {
    "suspicious_ips": {
      "terms": {
        "field": "source.ip",
        "size": 10,
        "min_doc_count": 100
      }
    }
  }
}
          • Security: Phát hiện tấn công Brute Force, Credential Stuffing.
          • Marketing: Tìm Top 10 sản phẩm được xem nhiều nhất.
          • SRE: Tìm các service đang gây ra nhiều lỗi 5xx nhất.
          Thử thách cho bạn

          Thống kê Top 5 người dùng (user.name) có số lượng request bị lỗi 403 (http.response.status_code) cao nhất.

          Xem đáp án
          {
  "size": 0,
  "query": {
    "term": { "http.response.status_code": 403 }
  },
  "aggs": {
    "top_violators": {
      "terms": {
        "field": "user.name",
        "size": 5
      }
    }
  }
}

          Quick Reference Cheat Sheet

          Mục tiêu Query Type Ghi chú quan trọng
          Tìm giá trị chính xác term Dùng cho keyword, không dùng cho text đã qua phân tách (analyzed).
          Tìm kiếm văn bản match Hỗ trợ tìm kiếm mờ, không phân biệt hoa thường.
          Lọc theo thời gian/số range Dùng gte (>=), lte (<=), gt (>), lt (<).
          Kết hợp nhiều điều kiện bool must (AND), should (OR), must_not (NOT), filter (AND - No score).
          Phân tích/Thống kê aggs Đặt "size": 0 nếu chỉ muốn lấy kết quả thống kê, không lấy tài liệu.

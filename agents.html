VS Code · GitHub Copilot

Cài custom agent vào workspace

Tài liệu VS Code ↗
01

Tạo agent profile

Mở Chat → Open Customizations → Agents → New Custom Agent và chọn Workspace.

02

Copy file hoàn chỉnh

Chọn một agent, mở chi tiết rồi nhấn Copy for VS Code. Dán toàn bộ YAML frontmatter và prompt để thay nội dung template.

03

Chọn agent trong Copilot

File workspace nằm tại .github/agents/<agent-name>.agent.md. Trong Chat, chọn Session Target Copilot, sau đó chọn custom agent trong menu Agent.

Cài thủ công cũng được: tạo `.github/agents/` trong workspace, lưu nội dung đã copy thành `.agent.md`, rồi mở lại Agent dropdown. Hãy xem lại `tools` trong frontmatter và chỉ cấp quyền cần thiết cho vai trò.

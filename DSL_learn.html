Nội dung học tập chi tiết

Cấp độ 1: Tìm kiếm chính xác (Term Level Queries)

Lesson 1 Term Query - Tìm chính xác
Tình huống: Tìm tất cả các log có status_code đúng bằng 500.
JSON DSL
{
  "query": {
    "term": {
      "status_code": 500
    }
  }
}
Lesson 2 Range Query - Tìm trong khoảng
Tình huống: Tìm request có thời gian phản hồi (latency) > 2000ms.
JSON DSL
{
  "query": {
    "range": {
      "response_time": {
        "gt": 2000,
        "lte": 5000
      }
    }
  }
}

Cấp độ 2: Logic & Tìm kiếm toàn văn (Full-text)

Lesson 3 Bool Query - Kết hợp logic
Tình huống: Tìm log service "order", level "ERROR", nhưng KHÔNG phải lỗi "Timeout".
JSON DSL
{
  "query": {
    "bool": {
      "must": [
        { "term": { "service": "order" } },
        { "term": { "level": "ERROR" } }
      ],
      "must_not": [
        { "match": { "message": "Timeout" } }
      ]
    }
  }
}

Cấp độ 3: Phân tích & Thống kê (Aggregations)

Lesson 4 Terms Aggregation - Top lỗi
Tình huống: Thống kê 5 loại exception_class xuất hiện nhiều nhất.
JSON DSL
{
  "size": 0,
  "aggs": {
    "top_errors": {
      "terms": {
        "field": "exception_class.keyword",
        "size": 5
      }
    }
  }
}
